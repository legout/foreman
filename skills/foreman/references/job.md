# Bounded factory job

Load `planning-contract` and `agent-guardrails`, then check the repository's `AGENTS.md`. Treat the owner's request as execution approval only for a clear bounded goal within that grant. If architecture, a separate spec, a material unresolved decision, or more than five tasks are needed, route to `shape-design` without creating issues.

Run startup preflight. Open an epic with the owner goal, scope, non-goals and checkable goal criteria. Split into at most five issues, including a verifier-only final issue that depends on all implementation issues. Use the issue fields, lane mapping and edge-writing steps in [plan-to-issues.md](plan-to-issues.md), citing the owner request and epic as the source.

Record the epic CI baseline, then run the factory loop scoped to this epic without a second approval. Keep state on GitHub.
